# Women Safety Alert System

An advanced emergency alert platform built using **Python**, **Django**, **SQLite**, **Twilio**, and **SMTP** that helps women quickly send real-time **SMS and Email alerts** with **live location tracking** to their trusted contacts during emergencies.

## Features

- **One-Touch SOS Alert:** Instantly trigger emergency notifications.
- **Real-Time Location Sharing:** Sends a live Google Maps link of user's location.
- **SMS Alert via Twilio API:** Reliable and instant messaging to registered mobile numbers.
- **Email Alert via SMTP:** Emergency emails sent to registered email addresses with location details.
- **User Authentication:** Secure user registration and login system.
- **Manage Emergency Contacts:** Add, edit, or delete emergency contacts.
- **Admin Panel:** Django admin dashboard to manage users and monitor alerts.
- **Lightweight Database:** Uses SQLite for fast and easy data management.
- **Responsive UI:** Optimized for mobile and desktop users (basic frontend enhancements).

## Technologies Used

| Technology              | Purpose                        |

| SMTP (Gmail/Custom)     | Sending Email Alerts           |
| HTML5, CSS3,            | Frontend Design                |
| Geolocation API (HTML5) | Fetching GPS Location          |

## 👋🏻 Walkthrough

1. Install django and Requests
 
sh
pip install -r requirements.txt
pip install python-dotenv twilio



2. Fill the details in
  

main_app/mail.py
mysite/settings.py


3. Run the website by following command in the terminal

sh
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
